# Adobe Bridge – Clone Rating

Adobe Bridge 시작 스크립트입니다. 한 폴더의 파일에 매긴 별점(star rating)을, 같은 이름(확장자 제외)을 가진 다른 폴더의 파일에 복사합니다.

전형적인 용도: 카메라가 함께 저장한 JPG와 RAW(CR3, RAF, DNG 등) 중 JPG만 보면서 별점을 매긴 뒤, 그 별점을 RAW 파일에 그대로 옮기는 작업입니다.

## 기능

- 소스 폴더와 타깃 폴더는 경로를 붙여 넣거나 `Browse...`로 고릅니다. 폴더 구조에 제한이 없습니다. 같은 폴더를 소스와 타깃으로 골라도 됩니다.
- 소스 폴더 안에 확장자가 여러 종류이면, 어느 확장자의 파일에서 별점을 읽을지 드롭다운으로 고릅니다. 타깃도 마찬가지로 전체 또는 특정 확장자를 고릅니다.
- 파일 포맷에 제한이 없습니다. 짝은 확장자를 뺀 파일 이름으로만 맞춥니다. 대소문자는 구분하지 않습니다.
- 진행 상황, 경고, 요약, 쓰기 결과를 창 하나에서 확인합니다. 창 위쪽 단계 표시줄(`Setup > Read > Review > Write > Done`)이 현재 단계를 보여 주고, 상태줄에 하위 단계 번호, 처리 속도, 남은 시간이 나옵니다. 주요 건수는 요약 패널에 숫자로 표시됩니다.
- 읽기가 끝나면 변경 예정 목록을 보여 주고, Write 버튼을 눌러야만 실제로 씁니다. 기존 별점을 다른 값으로 바꾸는 파일이 있으면 한 번 더 확인합니다.
- 쓰기 전에 기존 `.xmp` 사이드카를 백업하고, 메타데이터를 파일 안에 쓰는 형식(JPG, TIFF, DNG 등)은 원본 파일을 통째로 백업합니다.
- 쓴 뒤에는 별점을 디스크에서 다시 읽어 확인합니다. CSV 로그는 첫 쓰기 전에 만들어 두고 파일마다 결과를 바로 추가합니다.

## 설치

1. `Clone-Rating.jsx`를 Bridge 시작 스크립트 폴더에 복사합니다.
   - Windows: `%APPDATA%\Adobe\Bridge 2026\Startup Scripts\`
   - macOS: `~/Library/Application Support/Adobe/Bridge 2026/Startup Scripts/`
   - 다른 버전은 폴더 이름의 `2026`을 해당 버전으로 바꿉니다.
2. Bridge > 편집 > 환경 설정 > 시작 스크립트에서 `Clone-Rating`에 체크합니다.
3. Bridge를 완전히 종료한 뒤 다시 실행합니다.
4. 메뉴 `Tools > Clone Rating`이 보이면 설치된 것입니다.

스크립트가 로드되는지 확인하려면 임시 폴더의 `Clone-Rating.load.log`를 봅니다. Windows에서는 `%TEMP%\Clone-Rating.load.log`입니다.

## 사용

1. `Tools > Clone Rating`을 실행합니다.
2. 창에 소스 폴더(별점을 읽어 올 폴더)와 타깃 폴더(별점을 써 넣을 폴더)의 경로를 넣고 `OK`를 누릅니다. 경로 칸에서 Enter를 눌러도 됩니다.
   - 탐색기 주소 표시줄에서 복사한 경로, 또는 `Shift`+우클릭 > `경로로 복사`(`Copy as path`)로 복사한 따옴표 붙은 경로를 그대로 붙여 넣으면 됩니다. 앞뒤 공백, 따옴표, 끝의 `\`는 무시합니다.
   - `Browse...`를 누르면 폴더 선택 창이 열립니다. 칸에 이미 경로가 있으면 그 폴더에서 시작합니다. 폴더를 고르면 경로 입력 창이 다시 열리고, 입력해 둔 값은 그대로 남아 있습니다.
   - 없는 폴더를 넣으면 창이 다시 열리고 `Source folder not found` 또는 `Target folder not found`가 표시됩니다.
3. 소스 폴더에 확장자가 둘 이상이면 어느 확장자를 읽을지 고릅니다.
4. 타깃 확장자를 고릅니다. 기본값은 `All files`입니다.
5. 창에서 `Start reading`을 누릅니다. 읽는 동안 Bridge가 잠시 응답하지 않을 수 있습니다. 진행 상황은 창의 상태줄과 진행 막대, 그리고 타깃 폴더의 `_rating_sync_progress.txt`에 기록됩니다.
6. 요약 패널과 변경 예정 목록을 확인하고 `Write N files`를 누릅니다. `Cancel`을 누르면 아무것도 쓰지 않습니다. 기존 별점이 바뀌는 파일(`Replace a rating`)이 있으면 바로 쓰지 않습니다. 로그에 바뀌는 별점 목록(최대 20개)과 소스·타깃 폴더가 나오고, 버튼이 `Confirm: write N, replace M`으로 바뀝니다. 이 버튼을 한 번 더 눌러야 씁니다. 소스와 타깃을 뒤바꿔 골랐다면 `Cancel`을 누릅니다.
7. 끝나면 상태줄에 결과가 `Finished`, `Stopped`, `Aborted` 중 하나로 표시됩니다. `Open log`, `Open backup`, `Show target in Bridge` 버튼으로 로그, 백업 폴더, 타깃 폴더를 바로 엽니다.

### 별점 처리 규칙

| 소스 별점 | 타깃 별점 | 동작 |
|---|---|---|
| 1~5 | 다름 | 소스 값으로 덮어씀 |
| 1~5 | 같음 | 건너뜀 (Already equal) |
| 0 (없음) | 1~5 또는 거부 | 타깃 별점을 지움 (`WRITE_ZERO: true`). 기존 별점을 바꾸는 것이므로 덮어쓰기 확인 단계를 거침 |
| 0 (없음) | 0 (없음) | 건너뜀 (Already equal) |
| -1 (거부) | 무엇이든 | 건너뜀 (`SYNC_REJECT: false`) |

- 소스에는 있는데 타깃에 짝이 없는 파일: 별점이 있으면 경고로 표시하고 CSV에 기록합니다. 쓰기는 하지 않습니다.
- 타깃에는 있는데 소스에 짝이 없는 파일: 건수만 요약에 표시합니다.
- 같은 폴더 안에 이름이 같은 파일이 둘 이상이면(예: `a.cr3`와 `a.dng`) 그 이름은 건너뜁니다. 두 파일이 `a.xmp` 사이드카 하나를 공유하기 때문입니다.

### 타깃 폴더에 생기는 파일

- `_rating_sync_progress.txt`: 현재 진행 단계. 실행 중 덮어씁니다.
- `_rating_sync_log_YYYYMMDD_HHMMSS.csv`: 모든 파일의 처리 결과. 열은 `target, source, target_before, source_rating, result`. 첫 쓰기 전에 모든 변경 예정 행을 `pending: not written yet`으로 기록하고, 파일마다 결과 행을 끝에 추가하며, 마지막에 전체를 다시 씁니다. Bridge가 쓰는 도중 멈춰도 이전 별점(`target_before`)이 남습니다. 로그를 만들 수 없으면 아무것도 쓰지 않습니다. 중단되면 남은 파일은 `not processed: run stopped`로 기록됩니다.
- `_rating_sync_backup_YYYYMMDD_HHMMSS/`: 쓰기 전에 존재하던 `.xmp` 사이드카의 사본, 그리고 파일 자체가 바뀐 타깃(JPG, TIFF, DNG 등)의 원본 사본. 백업할 것이 없으면 폴더를 지웁니다.

이 파일들은 다음 실행 때 짝짓기 대상에서 제외됩니다.

## 설정

스크립트 상단 `CONFIG`에서 바꿉니다.

| 키 | 기본값 | 의미 |
|---|---|---|
| `WRITE_ZERO` | `true` | 소스가 별점 없음(0)이면 타깃 별점도 지웁니다. 소스에서 별을 지운 것이 타깃에 반영됩니다. `false`이면 별점 없는 소스는 건너뛰고 타깃 별점을 그대로 둡니다. |
| `SYNC_REJECT` | `false` | `true`이면 소스의 거부(-1) 표시도 타깃에 복사합니다. |
| `BACKUP_XMP` | `true` | 쓰기 전에 기존 `.xmp` 사이드카를 백업합니다. |
| `BACKUP_EMBEDDED` | `true` | 사이드카가 없고 RAW가 아닌 타깃은 쓰기 전에 파일 전체를 백업합니다. 쓴 뒤 파일이 바뀌지 않았으면 사본을 지웁니다. DNG처럼 매번 파일이 바뀌는 형식은 바뀐 파일 크기만큼 디스크를 씁니다. |
| `FAST_READ` | `true` | 별점을 XMP에서 직접 읽습니다. `false`이면 모두 Bridge를 통해 읽습니다. |
| `FAST_READ_CHECK` | `100` | 직접 읽은 값 중 몇 개를 Bridge 값과 대조할지. 하나라도 다르면 전체를 Bridge로 다시 읽습니다. |
| `PROGRESS_FILE` | `true` | 진행 파일 `_rating_sync_progress.txt`를 씁니다. |

## 동작 원리

### 짝짓기

파일 이름에서 마지막 확장자를 떼고 소문자로 바꾼 값을 키로 씁니다. `IMG_0001.JPG`와 `IMG_0001.CR3`는 키 `img_0001`로 같은 짝이 됩니다.

### 별점 읽기

Bridge 별점은 XMP의 `xmp:Rating` 속성입니다. 값의 범위는 -1(거부), 0(없음), 1~5입니다.

소스 파일은 세 단계로 읽습니다.

1. 같은 이름의 `.xmp` 사이드카가 있으면 그 안의 `xmp:Rating`. RAW 파일과, Content Credentials가 들어 있는 JPG가 여기에 해당합니다.
2. 사이드카가 없거나 사이드카에 별점이 없으면 파일 안에 내장된 XMP 패킷(`XMPFile`).
3. 둘 다 실패하면 Bridge의 `Thumbnail.rating`. 느리지만 Bridge가 보는 값 그대로입니다.

직접 읽기는 Bridge의 썸네일과 캐시 작업을 거치지 않아 빠릅니다. 대신 최대 `FAST_READ_CHECK`개를 골라 Bridge 값과 대조하고, 하나라도 다르면 전체를 Bridge로 다시 읽습니다.

소스와 타깃이 같은 폴더이면 `.xmp` 사이드카가 어느 파일 것인지 이름만으로는 알 수 없으므로, 소스 별점은 항상 Bridge를 통해 읽습니다.

타깃 파일은 사이드카를 먼저 읽습니다. 사이드카가 없는 RAW 파일은 Bridge에서 별점을 매긴 적이 없는 파일이므로, 카메라가 파일 안에 넣은 XMP를 직접 읽습니다. Bridge가 보여 주는 값도 이것입니다. 그 밖의 경우(사이드카가 없는 JPG·DNG 등, 사이드카에 `xmp:Rating`이 없음, 직접 읽기 실패)에는 Bridge에 묻습니다.

### 별점 쓰기

`new Thumbnail(file).rating = value`로 씁니다. Bridge가 파일 포맷에 맞게 `.xmp` 사이드카 또는 파일 내장 XMP에 기록합니다.

쓰기 전:

- 기존 `.xmp` 사이드카를 백업 폴더에 복사합니다(`BACKUP_XMP`).
- 사이드카가 없고 RAW 확장자가 아닌 파일은 파일 전체를 백업 폴더에 복사합니다(`BACKUP_EMBEDDED`). 복사에 실패하면 그 파일은 쓰지 않습니다.

쓰기 직후 타깃 파일의 크기와 수정 시각을 비교합니다.

- 사이드카가 있던 파일인데 파일 자체가 바뀌면 즉시 중단합니다.
- RAW 확장자(CR2, CR3, NEF, ARW, RAF, ORF, RW2, PEF, SRW 등)인 파일이 바뀌면, 사이드카가 없었더라도 즉시 중단합니다. RAW 원본은 바뀌면 안 되기 때문입니다. DNG는 Bridge가 파일 안에 쓰므로 이 목록에 없습니다.
- 그 밖의 파일(JPG, DNG, TIFF 등)이 바뀌면 내장 XMP에 쓴 것이므로 정상으로 처리하고 백업 사본을 남깁니다. 파일이 바뀌지 않았으면 사본을 지웁니다.

마지막으로 별점을 디스크에서 다시 읽어 쓴 값과 비교합니다. 다르면 오류로 기록합니다. 사이드카가 있으면 사이드카만 봅니다. Bridge는 별점을 지울 때 `xmp:Rating` 항목을 삭제하므로, 항목이 없으면 0으로 봅니다. 사이드카가 없으면 파일 안의 XMP를 읽습니다.

## 문제 해결

- `Tools` 메뉴에 항목이 없음: 환경 설정 > 시작 스크립트에서 체크가 풀려 있는지 확인합니다. Bridge는 로드에 실패한 스크립트를 다음 실행 때 자동으로 끕니다. `%TEMP%\Clone-Rating.load.log`에 기록이 없으면 스크립트 평가 자체가 실패한 것입니다. 파일이 BOM 없는 UTF-8 또는 ASCII인지, 파일 중간에 비ASCII 문자가 없는지 확인합니다.
- `Error line 1: Cannot convert`: 스크립트 파일 안에 Bridge가 UTF-16으로 변환하지 못하는 문자가 있습니다. 위와 같이 확인합니다.
- 읽는 동안 창이 멈춘 것처럼 보임: 타깃 폴더의 `_rating_sync_progress.txt`로 진행 상황을 확인할 수 있습니다.

## 요구 사항

- Adobe Bridge 2026 (ExtendScript). 다른 버전은 시작 스크립트 폴더 이름만 다릅니다.
- `AdobeXMPScript` 라이브러리. Bridge에 포함되어 있습니다. 없으면 모든 파일을 Bridge를 통해 읽습니다.
